# **App Name**: AuraStream

## Core Features:

- Live Composite Dashboard: A centralized UI for monitoring the live feed status and controlling stream output from the VM environment.
- Generative Aurora Fallback: A real-time animated background engine using Canvas to create the Aurora Boreal effect when no background video is present.
- AI Description Tool: A feature powered by generative AI that serves as a tool to expand track metadata into creative, rhythmic descriptions for the overlay display.
- Automated Audio Sequencer: Logic to read local directories, loop audio files infinitely, and handle crossfading within the VM.
- Miniplayer Overlay Engine: A customizable, positioned visual layer that displays real-time track metadata in the bottom-right corner.
- RTMP/SRT Broadcast Bridge: Integrated FFmpeg pipe that captures the local web rendering and audio to output a professional stream feed to YouTube.
- Asset Synchronization System: Automated watch-dog for the media folders to update the stream queue without requiring server restarts.

## Style Guidelines:

- The primary color is a vibrant Crimson (#EB2E4E), evoking the intensity of live broadcast. The background is a deeply desaturated near-black Charcoal (#141011) to ensure the visual elements and Aurora gradients stand out. An accent color of Orchid (#D629AD) is used for active miniplayer elements to provide professional contrast.
- A font pairing of 'Space Grotesk' for headlines to provide a high-tech, precise feel, and 'Inter' for body text to ensure absolute readability for track titles and descriptions.
- Minimalist outline icons representing playback, signal strength, and file status to maintain a clean, 'pro-app' look that stays out of the way of the content.
- An asymmetrical, low-profile overlay system that prioritizes the visual real estate of the stream while docking technical info in corners.
- Slick, fluid transitions for the metadata display and gentle easing on the generative Aurora gradients for a cinematic background feel.
