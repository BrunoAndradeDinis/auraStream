# Brand & Style

AuraStream v2.0 adota uma estética "Abyssal Aurora", combinando o minimalismo agressivo de interfaces hacker (True Black) com a fluidez técnica de ferramentas para desenvolvedores. É projetado para uso em sessões extensas, privilegiando contraste absoluto e leitura rápida de logs/dados.

## Colors

- **Background:** True Black (`#000000`) para o fundo principal, eliminando distrações.
- **Surface:** Deep Slate (`#020617`) para elevação de painéis no Dashboard.
- **Accents:** Cyan Neon (`#00F0FF`) para ações primárias e status; Roxo Profundo (`#7C3AED`) para a névoa da Aurora Boreal no MiniPlayer e glow de componentes.

## Typography

- **Títulos (Headings):** `Outfit` — Traz precisão geométrica e uma pegada limpa para os cabeçalhos.
- **Dados & Logs (Mono):** `JetBrains Mono` — Para a listagem da fila, tempos (03:14) e logs no Dashboard. Perfeito para leitura técnica.
