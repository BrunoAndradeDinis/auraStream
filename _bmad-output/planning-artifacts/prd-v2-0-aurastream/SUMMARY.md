# 🚀 AuraStream v2.0 — Quick Reference

**Status**: PRD Draft ✅ | Architecture 🚧 | Development ⏳

---

## ⚡ What's New in v2.0

| What | Details | Why |
|------|---------|-----|
| **Audio Sequencer** | MP3, WAV, FLAC, OGG loop + crossfade + skip/reorder | Production radio feel |
| **CLI Interface** | Terminal menu (Pause/Continue/Stop/Restart) | VM headless operation |
| **RTMP Bridge** | YouTube transmit (3-5 Mbps, reconnect auto) | 24/7 streaming |
| **Asset Sync** | Auto-detect new audio/metadata/video (no restart) | Dynamic playlist |
| **MiniPlayer** | Overlay cinematic, title/artist/genre/IA desc | YouTube viewer experience |
| **Auto-Shutdown** ⭐ | Timers: 1h, 2h, 3h, 1d, 2d, 3d, 1w, 2w, 3w | Automation |

---

## 🎮 How to Use (CLI — Primary)

```bash
# Start
npm run cli
? Select action: > Start streaming

# Pause to add tracks (RTMP continues)
> Pause
# [ Copy new files to ./src/assets/audio/ ]
> Continue

# Auto-stop after 3 hours
? Set auto-shutdown: > 3 hours
# System will stop at that time

# Manual stop
> Stop streaming
```

## 📞 Support & Debugging

### **CLI Menu Stuck?**
```bash
# Kill and restart
npm run cli
```

### **RTMP Connection Failed?**
```bash
# Check YouTube key
npm run cli
? Configure stream key: ✓

# Check network
curl -I https://a.rtmp.youtube.com/

# Logs
tail -f ./logs/aurastream.log
```

### **Audio Not Playing?**
```bash
# Check audio file exists and is valid
ffprobe ./src/assets/audio/your-file.mp3

# Check Web Audio in browser console
window.AudioContext
```
