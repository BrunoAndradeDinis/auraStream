## Entry 2 — Three Feature Fronts (Acceptance)

**Date**: 2026-06-06
**Decision**: Scope v2.0 em exatamente 3 frentes: Audio Sequencer, RTMP Bridge, Asset Sync

**Rationale**:
- MVP completeness (v1 tinha stubs)
- UI/UX elevation como quarta frente integrada
- 5-week sprint realista (~1 semana por frente)

**Scope Decisions**:
- **Excluded**: Playlist presets, chat integration, multi-platform, audio effects, user accounts
- **Included**: Crossfade (Web Audio), YouTube key management (localStorage + env fallback), MiniPlayer as pure display

**Status**: ✅ Framed em FR-1.1, FR-1.2, FR-1.3, FR-2.1, FR-2.2

---

## Entry 3 — Audio Formats & Sequencing

**Date**: 2026-06-06
**Decision**: Support MP3, WAV, FLAC, OGG; Loop infinito + Crossfade 500ms + Playlist dinâmica (skip, reorder, remove)

**Rationale**:
- Bruno quer flexibilidade (não só MP3)
- Crossfade critical pra smooth radio feel
- Dinâmica (skip, reorder) pra durante-transmissão control

**Tech Assumption**: Web Audio API + FFmpeg pipe (local or wasm)
**Status**: ✅ FR-1.1 detailed

---

## Entry 4 — RTMP/SRT Strategy

**Date**: 2026-06-06
**Decision**: Integra FFmpeg no projeto (greenfield setup); YouTube RTMP primário; SRT como option

**Rationale**:
- Bruno quer "zero coisas externas" — integrado no projeto
- YouTube é target (RTMP padrão)
- SRT fallback se RTMP cair
- FFmpeg wasm ou Node.js child_process (depends on VM perms)

**Scope**: 1920×1080 @ 30fps, 3-5 Mbps adaptive, reconnect 5x exponential backoff
**Status**: ✅ FR-1.2 detailed, tech TBD em Architecture phase

---

## Entry 5 — Asset Sync Philosophy

**Date**: 2026-06-06
**Decision**: Watch `./src/assets/audio/`, `details/`, `video/` em polling 2s; no restart needed

**Rationale**:
- Bruno adiciona áudio mid-stream
- Fila atualiza automáticamente
- Metadata JSON síncrono com audio files

**Contraints**: Details JSON priority over TXT; fallback se missing
**Status**: ✅ FR-1.3 detailed

---

## Entry 6 — Metadata Unification

**Date**: 2026-06-06
**Decision**: `.json` schema único por track (replace TXT); includes: title, artist, genre, subgenre, duration, source, aiDescription, tags

**Rationale**:
- TXT unstructured (current: só "Pull Me Down" + credits)
- JSON = queryable, composable, IA-ready
- On-demand generation: if missing, IA batch-generate + cache

**Assumption**: IA pode generar 50+ descriptions em <30s (vide Open Q)
**Status**: ✅ FR-3.1 detailed, schema exemplified

---

## Entry 7 — YouTube Stream Key Security Model

**Date**: 2026-06-06
**Decision**: Priority: UI localStorage > .env YOUTUBE_STREAM_KEY > empty; masked input; no logs

**Rationale**:
- Bruno quer flexibilidade (não hardcode)
- localStorage persists across sessions (UX good)
- .env fallback pra safety
- Masked + no-log pra security

**Assumption**: localStorage seguro o suficiente pra VM Magalu context (vide Open Q)
**Status**: ✅ FR-3.2 detailed

---

## Entry 8 — Dashboard Scope (Monitoramento Pessoal Only)

**Date**: 2026-06-06
**Decision**: Dashboard é **só pra Bruno monitorar**; não é viewer-facing; live status, queue, logs

**Rationale**:
- Separate concerns: Monitor (Bruno, backstage) ≠ MiniPlayer (viewers, on-screen)
- Real-time feedback <100ms criticality pra operator UX
- Logs + status pra debugging

**Scope**: Left sidebar, cards, drag-drop queue, stream config, video background, logs
**Status**: ✅ FR-2.1 detailed

---

## Entry 9 — MiniPlayer as Pure Display

**Date**: 2026-06-06
**Decision**: MiniPlayer = 99% display, fixed bottom-right, 280×140px, no interactivity

**Rationale**:
- "Cinematic" = smooth animations, not clicky
- YouTube viewers see it (não want clickable overlays)
- Cover art, title, artist, genre, subgenre, IA description
- Animations: fade-in 300ms, glow pulse 3s, slide-up on track change

**Visual**: Crimson title, Orchid border top, semi-transparent black bg, blur backdrop
**Status**: ✅ FR-2.2 detailed

## Entry 13 — Stream Control Operations

**Date**: 2026-06-06
**Decision**: Adicionar controles: Pause (sem parar RTMP), Continue, Stop, Restart

**Rationale**:
- Pause = Bruno adiciona tracks novas sem interrupção do stream (áudio parado mas transmissão segue)
- Continue = retoma áudio após pause
- Stop = interrompe tudo (áudio + RTMP)
- Restart = limpa estado, recomeça do zero

**Implementation**: Dashboard buttons + CLI menu equivalente
**Status**: ✅ Framed em FR-1.4 (nova)

---

## Entry 14 — Terminal CLI Interface

**Date**: 2026-06-06
**Decision**: Adicionar CLI interativa com menu (VMs sem GUI precisam de acesso terminal)

**Rationale**:
- VM Magalu rodando sem interface gráfica a maioria do tempo
- Bruno precisa de menu interativo para: Play, Pause, Continue, Stop, Restart, Config, Logs
- CLI = same UX do Dashboard mas via stdin/stdout

**Implementation**: Node.js CLI com inquirer/chalk pra menu pretty
**Tech Stack**: inquirer.js, chalk, commander.js (CLI framework)
**Status**: ✅ Framed em FR-2.3 (nova)

---

## Entry 15 — Auto-Shutdown Timers

**Date**: 2026-06-06
**Decision**: Adicionar timers pré-definidos para encerrar transmissão automaticamente (opcional)

**Rationale**:
- Bruno quer automação: set timer no início, sistema para sozinho
- Presets: 1h, 2h, 3h, 1d, 2d, 3d, 1w, 2w, 3w
- Opcional = não bloqueia v2.0 se não completar

**Behavior**:
- Timer visível no Dashboard + CLI
- Aviso 5min antes (toast + audio tone)
- Auto-stop: para áudio + fecha RTMP + logs "Scheduled shutdown"
- Cancelável a qualquer momento

**Status**: ✅ Framed em FR-4.1 (nova, opcional)
